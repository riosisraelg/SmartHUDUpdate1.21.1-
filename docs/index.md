# Smart HUD: Master Documentation Index (MDI)

Welcome to the Single Source of Truth (SSOT) for the **Smart HUD** Minecraft Mod architecture and engineering documentation.

## Project Overview
Smart HUD is a client-side Fabric mod for Minecraft 1.21.1 that provides extra HUD elements (Virtual Slots and an Item Pickup Ticker) to enhance user experience without cluttering the main hotbar.
